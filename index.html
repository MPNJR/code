Setup guide — the desktop tools (optional, do it on your PC when ready)

You do not need any of this to start — every lesson, this Practice area, Spark and the Grounds already run in the site. Set these up on your home PC whenever you feel like it. It's a one-time thing, and this guide stays here so you never have to remember the steps.

1Install VS Code

code.visualstudio.com — the free desktop editor most developers use. Big download, then just click through.

2Add three extensions

Inside VS Code: Live Server (see your page update instantly), Prettier (auto-tidies messy code), Error Lens (shows mistakes right on the line).

3Make one folder

A folder called coding-school with a sandbox folder inside it to mess around in. That's your workbench.

4That's it

Open that folder in VS Code and you're set up like a pro. Your phone and Mac lessons still need none of this.
